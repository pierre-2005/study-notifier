## v3.7.1 integration follow-up

A final review found that date-only all-day cache values were treated as midnight UTC in the full calendar, shifting them to the previous date west of UTC. Shared cache projection now preserves all-day dates in Calendar, Today’s mini-calendar and agenda, including pre-v3.7 rows with no flag. Floating ICS times use the viewing timezone; historical suffix-free Microsoft times remain UTC. All-day reminders use the personal date-only time instead of a provider’s midnight. Added three precision tests and an authenticated cross-view/ownership acceptance test. This follow-up uses its own branch/PR and repeats the full release checks before merging. Its distinct `v3.7.1` image avoids races with the initial v3.7.0 publication.

The follow-up CI selects GitHub's installed Chrome when present, avoiding a redundant browser download that stalled earlier runs. A bounded headless-Chromium install remains the fallback; all browser suites still run. The browser version is printed in the run log. This follows [GitHub runner image software](https://github.com/actions/runner-images/blob/main/images/ubuntu/Ubuntu2404-Readme.md) and [Playwright browser support](https://playwright.dev/python/docs/browsers). No regression or accessibility check is skipped.
