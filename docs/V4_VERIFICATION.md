## Migration and compatibility

The pre-v3.7 historical fixture tests remain. An additional synthetic fixture was
generated by the exact released v3.7.1 code, with provenance and SHA-256 in
`tests/fixtures/v371_baseline.json`. It contains 66 original tables, released
workspace/reminder preferences, existing accounts/project roles, encrypted OAuth
credentials, Finance frequencies, a deliberately deleted merchant rule, a private
course and note text. The rehearsal preserves every original column/row, adds
only the new schema, migrates twice, includes uncheckpointed WAL data, verifies
restoration equality and checks attachment hashes and authenticated isolation.
Actual installation backup rehearsal remains an owner step.

`/api/v4` is canonical; `/api/v37` remains a tested alias. Historical static URLs
remain served so installed clients can finish/refresh. Classic to-do mutations
use real current tasks and their transition rules; deleted migrated tasks stay
tombstoned. Original storage objects are not renamed for branding.

## Limits and operator gates

Automated accessibility is partial evidence, not certification or a screen-reader
user study. QEMU ARM64 startup is not physical Pi performance or proof for a
32-bit OS. Mocked SMTP/OAuth/ntfy/AI checks do not establish real delivery,
provider approval, paid model quality, quotas or Store acceptance. Actual backup,
SMTP, Google/Microsoft, phone and installed-PWA acceptance remain explicit in the
[setup](V4_SETUP_REPORT.md) and [deployment/rollback](V4_DEPLOYMENT.md) reports.

Historical Finance/academic/job ownership remains bound to the original owner.
The statement parser remains BMO/Scotiabank PDF-specific; course import focuses
on reviewed assessments; notes use a bounded Markdown subset; ICS feeds are
read-only. No offline editing, live collaborative block editor, universal bank
parser, competitor parity or infrastructure-level inability to read server-side
plaintext is claimed.

The first final-head Linux run passed the 33 other scripts and both container
build/start jobs, then caught a transient signup contrast failure during its
opacity entrance animation. The opacity fade was removed so the text retains
its normal contrast throughout; the small position animation remains. Full
CI is required again for the corrected final head.
